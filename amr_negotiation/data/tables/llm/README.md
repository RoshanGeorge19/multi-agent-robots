# `data/tables/llm/`: one table per LLM run

`llm_<tag>.md` is written by [`experiments/llm/llm_negotiation.py`](../../../experiments/llm/README.md) at the end
of each run. Each table holds:
- the model and server;
- per policy arm: success, collisions, excess delay over the best forced yielder (mean ± 95% CI), reference-yielder rate, fallback rate and charged think time;
- a per-layout split.

The baselines (fixed priority, rulebook, `cost_bid`) appear in every table on the same encounters.

What each tag means (stage, model, settings, and which runs paper 2 excludes):
[`reports/llm/README.md`](../../../reports/llm/README.md). Per-episode data:
[`data/raw/llm/`](../../raw/llm/README.md).

Some tables open with "Generated by `studies/llm_negotiation.py`". They were written before the restructure, and
the script now lives in `experiments/llm/`.
